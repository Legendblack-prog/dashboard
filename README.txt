PWA «Дашборд сигналов Bybit» v1.0

Как открыть
-----------
1) Нужен HTTPS или localhost (PWA так устроена).
   Простой способ с компа:
     cd bybit-pwa
     python3 -m http.server 8080
   Открыть на телефоне в той же Wi‑Fi: http://IP_КОМПА:8080

2) Или залить папку на любой статический хостинг (GitHub Pages, Cloudflare Pages, Netlify).

Установка на экран
------------------
Chrome Android: меню → «Установить приложение» / «На экран Домой».
iOS Safari: Поделиться → На экран «Домой».

Что умеет
---------
• Live-свечи Bybit, скор, график, бумажные сделки, журнал
• Таймфреймы 1м…4ч, Д, Н
• ntfy push + браузерные уведомления (пока вкладка/PWA открыта)
• Сохранить журнал (JSON), отправить сводку в ntfy, очистить

Ограничение
-----------
Фон на телефоне слабый: пока приложение закрыто, скан не идёт.
Для 24/7 пушей — VPS или Termux на старом телефоне.
